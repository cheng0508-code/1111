# Mini · 德文卷毛猫主题网站

以家里的小猫 **Mini**（德文卷毛猫，生日 2025.04.12）为主题的单页展示网站。

## 本地预览

在项目目录下启动一个本地服务器，例如：

```bash
cd /Users/zhaoxinan/Desktop/111
python3 -m http.server 8080
```

浏览器打开 [http://localhost:8080](http://localhost:8080) 即可查看。

也可以直接用浏览器打开 `index.html` 文件。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（橙 / 黑 / 白 + 黄绿色点缀，呼应照片）
- `script.js` — 导航滚动等轻量交互
- `assets/` — Mini 的照片
